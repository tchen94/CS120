## Describe the API you selected and what it does

I selected the PokeAPI, which is a database for Pokemon information.
It provides information about the Pokemon that was queried, including its name, abilities, types, and more. The API allows users to retrieve data about different Pokemon by making requests to specific endpoints.

## Cite the website that offers the API

https://pokeapi.co/docs/v2#pokemon

## Describe the options/parameters you used for the API request -- i.e., what query info did you need to provide to the API to get your results?

I used a number paramater for the screenshot provided for this API. But,
for the actual implementation, I used a text input to allow users to search for Pokemon by name. The API request is made to the endpoint `https://pokeapi.co/api/v2/pokemon/{name}`, where `{name}` is replaced with the user-provided Pokemon name.

## Identify two applications where this API would be helpful.

This can be useful for a Pokemon fan website that provides detailed information about different Pokemon. It can also be used in a mobile app that allows users to look up Pokemon information on the go.
